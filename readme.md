# ProjectForge

ProjectForge is a modern collaborative project management platform built to help teams organize work, manage projects, assign tasks, and streamline communication in one unified workspace.

Designed as a productivity-focused solution, ProjectForge enables teams to manage project lifecycles efficiently through structured workflows, role-based collaboration, and task tracking.

## Features

- Secure user authentication and authorization
- Role-based access control for team collaboration
- Project creation, management, and organization
- Task assignment and progress tracking
- Subtask management for detailed workflow breakdown
- Team member invitation and permission management
- Project notes for collaboration and documentation
- File attachment support for tasks
- Email verification and password recovery
- RESTful API architecture
- Scalable backend structure for future expansion
